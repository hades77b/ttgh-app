개인정보처리방침

시행일: 2026년 10월 27일

「남보다 못한 가족 업로더」(이하 「이 앱」)는 YouTube 채널 「남보다 못한 가족」 운영자가 본인 채널을 관리하려고 쓰는 개인 도구입니다.

1. 사용하는 정보

이 앱은 운영자가 Google 계정으로 허용한 범위에서 YouTube Data API와 YouTube Analytics API를 사용해 다음을 다룹니다.

  • 운영자 본인 채널의 영상 업로드, 제목·설명·태그·공개 상태 수정
  • 운영자 본인 채널 영상의 댓글 읽기와 운영자 이름으로 댓글 작성
  • 운영자 본인 채널의 채널 정보와 조회수·시청시간 통계 읽기

2. 보관과 공유

  • 인증 토큰과 위 정보는 운영자의 기기에만 저장하며, 다른 사람이나 회사에 제공하거나 판매하지 않습니다.
  • 광고나 사용자 분석에 쓰지 않습니다.
  • 운영자 외의 사람에게서 개인정보를 모으지 않습니다. 운영자 채널에 달린 공개 댓글은 채널 관리 목적으로만 읽습니다.

이 앱이 Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 관련 약관

이 앱은 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

4. 권한 철회

Google 계정 → 보안 → 타사 앱 액세스에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다.

5. 문의

YouTube 채널 「남보다 못한 가족」의 정보 페이지를 이용해 주세요.
